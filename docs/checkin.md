# 签到与调度总览

返回：[项目主页](../README.md) / [文档目录](README.md) / [致谢与引用](references.md)

签到模块按 profile 执行，包含自动签到、游戏/社区签到开关、用户通知和随机/固定调度。

## 小功能

- [自动签到-多 profile](features/checkin.md)
- [签到调度-随机与固定](features/scheduler.md)

所有用户操作都允许在群聊执行。通知默认开启，私聊优先；若无法私聊，会在共同群聊 at 用户。

- 绝区零

国际服和云游戏默认隐藏，只有用户绑定对应 token/cookie 后才参与。

## 调度摘要

随机模式按 `random.window_start` 到 `random.window_end` 分配 profile。生成的是当天还是次日计划，由 `plan_generate_cron` 的触发时间和 `plan_date_cutoff_time` 分界共同决定：触发时间早于分界时生成当天计划，等于或晚于分界时生成次日计划。计划生成后会给用户发送签到时间图片；新注册 profile 会补入已有计划，不会重新洗牌。

锅巴面板和配置文件中的定时任务使用七段 cron。例如默认分界为 `13:00` 时，`0 0 0 * * ? *` 表示每天 00:00 生成当天计划。`catch_up_cron` 留空表示关闭补偿；设置后，插件会在错过生成任务时按相同日期规则补建计划。

自动签到与 `#开始签到[profile]`、`#手动签到[profile]` 等手动入口互不排斥。到期扫描只执行已有计划，清理计划文件后不会自动重建。
